## 📋 Funcionalidades
- **Extração de Dados:** Web Scraping autônomo de portais internos.
- **Relatórios:** Geração automática de arquivos preenchidos (Financeiro/Atividades).
- **Computer Vision:** Integração com IA para validar e redimensionar imagens do relatório.
